# 外协工序流转追踪系统 — 数据与接口契约

**版本**：v1.0  
**日期**：2026-06-18

---

## 1. 核心表结构

### 1.1 orders（订单表）
| 字段 | 类型 | 说明 |
|------|------|------|
| order_id | VARCHAR(64) | 主键，订单号 |
| product_name | VARCHAR(255) | 产品名称 |
| total_qty | INT | 订单总数 |
| order_status | VARCHAR(32) | 订单状态：pending/in_progress/completed |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### 1.2 process_records（工序流转记录表）
| 字段 | 类型 | 说明 |
|------|------|------|
| record_id | VARCHAR(64) | 主键，记录编号（扫码用） |
| order_id | VARCHAR(64) | 关联订单 |
| process_name | VARCHAR(255) | 工序名称 |
| process_index | INT | 工序排序（1,2,3...） |
| factory_id | VARCHAR(64) | 所属厂家 |
| record_status | VARCHAR(32) | 记录状态：pending/received/shipped/completed |
| total_receive_qty | INT | 累计接收数量 |
| total_ship_qty | INT | 累计发出数量 |
| return_qty | INT | 退件数量 |
| lock_type | VARCHAR(32) | 锁类型：none/entry_lock/relation_lock |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |
| last_received_at | DATETIME | 最后接收时间 |
| last_shipped_at | DATETIME | 最后发出时间 |

### 1.3 action_logs（操作日志表）
| 字段 | 类型 | 说明 |
|------|------|------|
| log_id | BIGINT | 主键 |
| user_id | VARCHAR(64) | 操作人 |
| action_type | VARCHAR(64) | 操作类型：RECEIVE/SHIP/UPDATE/... |
| target_table | VARCHAR(64) | 目标表 |
| target_id | VARCHAR(64) | 目标ID |
| old_value | JSON | 变更前值 |
| new_value | JSON | 变更后值 |
| created_at | DATETIME | 操作时间 |

### 1.4 users（用户表）
| 字段 | 类型 | 说明 |
|------|------|------|
| user_id | VARCHAR(64) | 主键 |
| username | VARCHAR(64) | 用户名 |
| password_hash | VARCHAR(255) | 密码哈希 |
| phone | VARCHAR(32) | 手机号 |
| role | VARCHAR(32) | 角色：admin/factory_admin/factory_operator |
| factory_id | VARCHAR(64) | 所属厂家（非 admin 必填） |
| status | VARCHAR(32) | 状态：active/disabled |
| created_at | DATETIME | 创建时间 |

### 1.5 factories（厂家表）
| 字段 | 类型 | 说明 |
|------|------|------|
| factory_id | VARCHAR(64) | 主键 |
| factory_name | VARCHAR(255) | 厂家名称 |
| contact_person | VARCHAR(64) | 联系人 |
| contact_phone | VARCHAR(32) | 联系电话 |
| status | VARCHAR(32) | 状态：active/disabled |
| created_at | DATETIME | 创建时间 |

### 1.6 notifications（通知表）
| 字段 | 类型 | 说明 |
|------|------|------|
| notification_id | BIGINT | 主键 |
| user_id | VARCHAR(64) | 接收用户 |
| title | VARCHAR(255) | 标题 |
| content | TEXT | 内容 |
| type | VARCHAR(32) | 类型：system/todo/warning |
| is_read | TINYINT(1) | 是否已读 |
| related_order_id | VARCHAR(64) | 关联订单（可选） |
| related_record_id | VARCHAR(64) | 关联记录（可选） |
| created_at | DATETIME | 创建时间 |

---

## 2. 关键索引
- `process_records(order_id, process_index)`：订单工序查询
- `process_records(factory_id, record_status)`：厂家待办查询
- `action_logs(target_table, target_id)`：操作历史查询
- `notifications(user_id, is_read)`：用户未读通知查询

## 3. API 契约总览

### 统一响应格式
```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

### 统一错误码
| 错误码 | 说明 |
|--------|------|
| 400 | 参数错误 / 业务校验失败 |
| 401 | 未认证 / Token 过期 |
| 403 | 无权限 / 跨厂操作 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 4. 核心接口字段契约

### 4.1 工序看板响应（ProcessKanbanResponse）
| 字段 | 类型 | 说明 |
|------|------|------|
| record_id | string | 记录编号 |
| process_name | string | 工序名称 |
| process_index | int | 工序排序 |
| factory_id | string | 所属厂家 |
| factory_name | string | 厂家名称 |
| record_status | string | 记录状态 |
| display_receive_qty | int | 展示接收数量（clamp 后） |
| display_ship_qty | int | 展示发出数量（clamp 后） |
| available_receive_qty | int | 可接收数量 |
| available_ship_qty | int | 可发出数量 |
| can_receive | bool | 当前用户是否可接收 |
| can_ship | bool | 当前用户是否可发出 |
| can_operate | bool | 当前用户是否可操作 |
| disabled_reason | string | 不可操作原因 |
| next_action | string | 下一步建议 |
| risk_level | string | 风险等级：normal/remind/warning/serious |
| stay_hours | float | 停留小时数 |
| last_received_at | string | 最后接收时间 |
| last_shipped_at | string | 最后发出时间 |
