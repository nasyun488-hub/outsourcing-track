# 外协工序流转追踪系统 — 部署运维说明

**版本**：v1.0  
**日期**：2026-06-18

## 1. Docker 部署流程

### 环境要求
- Docker 20.10+
- Docker Compose 2.0+
- 服务器内存 ≥ 2GB
- 硬盘 ≥ 20GB（系统 + 数据 + 日志）

### 部署步骤
```bash
# 1. 进入项目目录
cd /home/takemehome/outsourcing-track

# 2. 构建并启动所有服务
docker compose up -d

# 3. 查看服务状态
docker compose ps

# 4. 查看日志
docker compose logs -f backend
docker compose logs -f frontend
docker compose logs -f mysql
```

### 服务端口
| 服务 | 容器内端口 | 宿主机端口 | 说明 |
|------|-----------|-----------|------|
| backend | 8000 | 8000 | 后端 API |
| frontend | 80 | 8081 | 前端 H5 |
| mysql | 3306 | 3306 | MySQL 数据库 |

## 2. 常用运维命令

### 服务管理
```bash
# 启动所有服务
docker compose up -d

# 停止所有服务
docker compose down

# 重启单个服务
docker compose restart backend
docker compose restart frontend

# 重新构建并启动
docker compose up -d --build backend
docker compose up -d --build frontend
```

### 日志查看
```bash
# 查看所有服务日志
docker compose logs -f

# 查看单个服务日志
docker compose logs -f backend --tail 100
docker compose logs -f frontend --tail 100
docker compose logs -f mysql --tail 100
```

### 数据库操作
```bash
# 进入 MySQL 命令行
docker compose exec mysql mysql -uroot -prootpassword outsourcing_track

# 数据库备份
docker compose exec mysql mysqldump -uroot -prootpassword outsourcing_track > backup_$(date +%Y%m%d).sql

# 数据库恢复
docker compose exec -i mysql mysql -uroot -prootpassword outsourcing_track < backup_20260618.sql
```

### 演示数据

## 3. 配置说明

### 环境变量
| 变量 | 说明 | 默认值 |
|------|------|--------|
| MYSQL_ROOT_PASSWORD | MySQL root 密码 | rootpassword |
| MYSQL_DATABASE | 数据库名 | outsourcing_track |
| DATABASE_URL | 后端数据库连接 | mysql+pymysql://root:... |
| SECRET_KEY | JWT 密钥 | 随机生成（生产环境需修改） |
| ACCESS_TOKEN_EXPIRE_MINUTES | Token 有效期 | 1440（24 小时） |

### Nginx 配置（前端）
前端容器使用 Nginx Alpine，配置文件位置：
- 容器内：`/etc/nginx/nginx.conf`
- 挂载：如需自定义，可在 `frontend/Dockerfile` 中修改

## 4. 常见故障排查

### 故障 1：后端服务启动失败
**现象**：`docker compose ps` 显示 backend 重启中或 Exited

**排查步骤**：
```bash
# 1. 查看后端日志
docker compose logs backend --tail 50

# 2. 常见原因：
#    - 数据库连接失败：检查 MySQL 是否启动
#    - 数据库表不存在：需先初始化表（应用启动自动创建）
#    - 端口占用：检查 8000 端口是否被占用

# 3. 重启后端
docker compose restart backend
```

### 故障 2：前端页面白屏
**现象**：浏览器访问前端显示空白

**排查步骤**：
```bash
# 1. 检查前端容器状态
docker compose ps frontend

# 2. 查看前端日志
docker compose logs frontend

# 3. 浏览器控制台检查：
#    - API 请求是否 404：检查后端地址配置
#    - 是否有 JS 错误：前端构建问题

# 4. 重新构建前端
docker compose build frontend && docker compose up -d --no-deps frontend
```

### 故障 3：数据库连接失败
**现象**：后端日志显示 `Can't connect to MySQL server`

**排查步骤**：
```bash
# 1. 检查 MySQL 容器状态
docker compose ps mysql

# 2. 如果 MySQL 未启动，启动它
docker compose up -d mysql

# 3. 等待 10 秒后重启后端
sleep 10 && docker compose restart backend
```

### 故障 4：扫码无反应
**现象**：手机端点击扫码无反应

**排查步骤**：
1. 检查是否授予摄像头权限
2. 检查是否是 HTTPS 环境（部分浏览器要求 HTTPS 才能调摄像头）
3. 降级使用手动输入模式
4. 检查浏览器控制台是否有 `getUserMedia` 相关错误

### 故障 5：登录失败
**现象**：点击登录无反应或提示错误

**排查步骤**：
```bash
# 1. 检查后端 /health 是否正常
curl http://localhost:8000/health

# 2. 检查验证码接口是否正常
curl -X POST http://localhost:8000/api/auth/send-sms   -H "Content-Type: application/json"   -d '{"phone":"13800138000"}'

# 3. 常见原因：
#    - 手机号不存在：检查 users 表数据
#    - 验证码过期：演示环境验证码 5 分钟有效
#    - 密码错误：检查密码哈希或重置密码
```

## 5. 数据备份策略

### 数据库备份
- 频率：每日凌晨 2 点
- 保留：30 天
- 命令：
```bash
# 手动备份
docker compose exec mysql mysqldump -uroot -prootpassword outsourcing_track > /backup/outsourcing_track_$(date +%Y%m%d_%H%M%S).sql

# 自动备份（crontab）
0 2 * * * cd /home/takemehome/outsourcing-track && docker compose exec mysql mysqldump -uroot -prootpassword outsourcing_track > /backup/outsourcing_track_$(date +\%Y\%m\%d_\%H\%M\%S).sql
```

### 日志备份
- Docker 日志自动轮转，默认保留 5 个文件，每个 10MB
- 如需长期归档，可定期导出日志文件

## 6. 版本升级流程

```bash
# 1. 拉取最新代码
git pull origin master

# 2. 备份数据库
docker compose exec mysql mysqldump -uroot -prootpassword outsourcing_track > backup_before_upgrade.sql

# 3. 重新构建服务
docker compose build backend frontend

# 4. 重启服务
docker compose up -d

# 5. 验证健康检查
curl http://localhost:8000/health
curl http://localhost:8081

# 6. 运行验证脚本
python3 scripts/validate_main_flow.py
```

### 回滚流程
```bash
# 1. 回滚代码到上一版本
git reset --hard HEAD~1

# 2. 恢复数据库
docker compose exec -i mysql mysql -uroot -prootpassword outsourcing_track < backup_before_upgrade.sql

# 3. 重新构建并启动
docker compose build backend frontend && docker compose up -d
```
