## 5. 边界用例清单

### 数量边界
1. 接收数量 = 0 → 拒绝
2. 接收数量 = 最大可接收 → 正常
3. 接收数量 = 最大可接收 + 1 → 拒绝
4. 发出数量 = 0 → 拒绝
5. 发出数量 = 最大可发出 → 正常
6. 发出数量 = 最大可发出 + 1 → 拒绝
7. 历史毛数据超过订单量 → 展示层 clamp 正确

### 权限边界
1. 管理员操作 A 厂工序 → 允许
2. A 厂用户操作 A 厂工序 → 允许
3. A 厂用户操作 B 厂工序 → 403 拒绝
4. 禁用用户登录 → 拒绝
5. Token 过期访问 → 401 拒绝

### 异常场景
1. 重复扫码同一条记录 → 提示"已在清单中"
2. 扫码不存在的记录 → 提示"记录不存在"
3. 扫码跨厂记录 → 提示"无权操作其他厂家工序"
4. 清单为空时点击提交 → 按钮禁用
