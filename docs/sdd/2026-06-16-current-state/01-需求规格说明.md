# 需求规格说明

> 项目：外协工序流转追踪系统  
> 生成日期：2026-06-16  
> 当前基线：`9cc5f7d` / `baseline-h5-scan-2026-06-16`  
> 当前状态：后端/API/DB 主流程通过；H5 全页面体验优化与扫码购物车式录入已完成并部署；真实手机摄像头实拍扫码未做最终像素级闭环。

## 1. 业务背景

外协零件在多个厂家、多道工序间流转，传统方式容易出现：位置不清、数量不准、责任不可追溯、异常发现滞后、现场录入路径过长。本系统用于追踪外协零件从主厂到各外协厂家之间的接收、发出、退件与状态变化。

## 2. 用户角色

| 角色 | 主要诉求 | 权限边界 |
|---|---|---|
| 企业管理员 | 看全局、管厂家/人员、导出数据、处理异常 | 全局看板、管理、导出 |
| 主厂家管理员 | 关注主厂订单、协调外协厂、处理风险 | 主厂相关订单与人员 |
| 主厂家操作员 | 扫码接收/发出/退件，少输入 | 本厂可操作记录 |
| 外协厂家管理员 | 看本厂待处理、逾期、异常 | 本厂相关订单与人员 |
| 外协厂家操作员 | 按提示扫码录入接收/发出 | 本厂可操作记录 |

## 3. 功能需求

### FR-01 登录认证
- 手机号 + 验证码登录。
- 登录成功返回 token 与用户信息。
- 未登录访问受保护页面跳转登录。

### FR-02 订单/工序看板
- 订单列表、订单状态、当前卡点、流转进度。
- 支持待处理、逾期、今日更新等筛选体验。
- 详情页展示工序时间线、每道工序状态、下一步建议。

### FR-03 扫码录入
- 支持扫码枪、手机相机、拍照/相册识别、手工输入。
- 扫码后不跳页，加入本页清单。
- 自动判断接收/发出/查看/异常。
- 自动填入可用数量，允许按行修改、删除、重试、统一提交。

### FR-04 接收/发出/退件
- 接收不得超过可接收数量，支持分批。
- 发出不得超过可发出数量，支持分批。
- 退件从下道退回上道，影响净数量并写入退件记录。

### FR-05 通知/异常
- 展示相关通知。
- 支持单条已读、全部已读。
- 通知可作为待办入口跳转处理。

### FR-06 管理与导出
- 人员/厂家新增、审核、启用、禁用。
- Excel 导出，前端按 Blob 下载。

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 移动端体验 | 大按钮、大数字、少输入，适合现场单手操作 |
| 可追溯 | 每次接收/发出/退件有批次与操作人 |
| 数据一致性 | API 结果必须能被 DB 回查验证 |
| 安全 | token 认证、角色/厂家权限隔离 |
| 可部署 | Docker Compose 运行 backend/frontend/mysql |
| 可测试 | 主流程、H5、扫码契约脚本覆盖 |
