```bash

```

```bash
curl http://localhost:8000/health
curl http://localhost:8081/

```

## 2. 服务端口

| 服务 | 容器 | 主机端口 | 说明 |
|---|---|---:|---|
| MySQL | `outsourcing-track-mysql-1` | 3306 | 数据库 |
| Backend | `outsourcing-track-backend-1` | 8000 | FastAPI |
| Frontend | `outsourcing-track-frontend-1` | 8081 | H5/Nginx |

## 3. 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `MYSQL_ROOT_PASSWORD` | `rootpassword` | MySQL root 密码，生产必须改 |
| `MYSQL_DATABASE` | `outsourcing_track` | 数据库名 |
| `SECRET_KEY` | `change-me-in-production` | JWT 密钥，生产必须改 |
| `SMS_PROVIDER` | `mock` | 短信服务，演示为 mock |
| `LOG_LEVEL` | `INFO` | 后端日志等级 |

文档不得写入真实密码、token、短信验证码、密钥。

## 4. 构建与重启

前端重建：

```bash
cd /home/takemehome/outsourcing-track
(cd frontend && npm run build)
docker compose build frontend
docker compose up -d --no-deps frontend
```

后端重建：

```bash
cd /home/takemehome/outsourcing-track
docker compose build backend
docker compose up -d --no-deps backend
curl http://localhost:8000/health
```

## 5. 数据库注意事项

1. 初始化 DDL：`backend/migrations/T2_DDL.sql`。
2. 字符集：`utf8mb4` / `utf8mb4_unicode_ci`。
3. DB 回查脚本必须加 `--default-character-set=utf8mb4`。
4. 不要在脚本里硬编码数据库密码。

## 6. 常见故障

| 现象 | 处理 |
|---|---|
| `/health` 失败 | `docker compose logs backend --tail 80` |
| ORM mapper 报错 | 对照 `models/*` 与 DDL 检查字段、关系、枚举 |
| 前端接口不通 | 检查 Nginx 代理、后端容器、API 路径 |
| Docker 前端构建提示 bash | 检查并删除错误的 `frontend/.npmrc script-shell=/usr/bin/bash` |
| 中文乱码 | DB/客户端查询使用 `utf8mb4` |
| shell 找不到命令 | 显式设置标准 PATH |

## 7. 生产化建议

- 使用真实 `SECRET_KEY` 与短信服务配置。
- CORS 改为生产域名白名单。
- 前端启用 HTTPS，满足手机摄像头权限。
- 增加数据库备份、迁移、只读账号与审计。
- 增加 CI：编译、构建、契约测试、主流程验证。
