# 系统设计说明

> 项目：外协工序流转追踪系统  
> 生成日期：2026-06-16  
> 当前基线：`9cc5f7d` / `baseline-h5-scan-2026-06-16`  
> 当前状态：后端/API/DB 主流程通过；H5 全页面体验优化与扫码购物车式录入已完成并部署；真实手机摄像头实拍扫码未做最终像素级闭环。

## 1. 总体架构

```text
Vue3/Vant H5 前端
    │ Axios / JWT
    ▼
FastAPI 后端 API
    │ SQLAlchemy / PyMySQL
    ▼
MySQL 8.0 数据库
```

Docker Compose 编排：`mysql`、`backend`、`frontend`。

## 2. 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3、TypeScript、Vite、Vant、Pinia、Vue Router、Axios、@zxing/browser |
| 后端 | Python、FastAPI、SQLAlchemy、Pydantic、JWT、PyMySQL |
| 数据库 | MySQL 8.0、utf8mb4 |
| 部署 | Docker、Docker Compose、Nginx |
| 验证 | Python 脚本、curl、浏览器 DOM/控制台抽测 |

## 5. 核心业务流

```text
订单/工艺路线
  → process_records
  → 上道接收
  → 上道发出
  → 下道接收
  → 退件/异常处理
  → 完成/导出/追溯
```

扫码录入采用：连续扫码 → 入清单 → 默认数量 → 行内校验/改数量 → 统一提交 → 成功/失败分流。

## 6. 权限设计

- 所有业务页面需要登录。
- 管理页面需要企业管理员角色。
- 流转操作需校验用户所属厂家与记录所属厂家/上下道关系。
- 前端只做入口提示，后端做最终权限判定。
